# Ý tưởng dự án Project Manager

## 1. Hồ sơ thiết kế
- Lưu trữ DWG/PDF tập trung.
- Parser thông tin bản vẽ.
- Quản lý phiên bản.

## 2. Quản lý triển khai
- Biểu đồ Gantt tiến độ.
- Chụp ảnh công trường, nhật ký thi công.
- Quản lý phiếu yêu cầu nghiệm thu.

## 3. Quản lý vận hành
- Quản lý vòng đời thiết bị.
- Lên lịch bảo trì định kỳ.
- Dashboard báo cáo chỉ số vận hành.
