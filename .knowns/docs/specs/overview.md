# System Specifications & Features

## Feature Specs Overview
- **GIS Engine & Map Rendering**: Render bản đồ bằng MapLibre GL, tương thích Google Maps tiles, hỗ trợ vẽ vector, bbox selection và spatial queries.
- **PMP & Sync Module**: Đồng bộ dữ liệu thiết kế và hồ sơ công trình giữa local SQLite và server/P2P.
- **Box Selection & Field Mapping**: Xử lý chọn khoanh vùng nhiều đối tượng trên bản đồ và mapping trường dữ liệu giữa GIS và database.
- **Project File Export/Import**: Xuất file MSI, Excel, Docx và GeoJSON.
