# Legacy application snapshot

This archive preserves the active application source before the Vietnam Basemap workspace consolidation on 2026-08-12.

The sibling `manifest.json` records every archived file, byte size, and SHA-256 hash. Generated dependencies, build outputs, runtime databases, and temporary network files were intentionally excluded; see `excludedGeneratedData` in the manifest.

Restore by copying the archived relative paths back to the repository root only after reviewing the target state.
