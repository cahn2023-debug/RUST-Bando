# Project Manager

Phần mềm desktop tích hợp quản lý hồ sơ thiết kế, triển khai và vận hành.

## Trụ cột chính:
1. **Hồ sơ thiết kế**: Quản lý bản vẽ, tài liệu kỹ thuật.
2. **Quản lý triển khai**: Theo dõi tiến độ, vật tư, nhân lực trên công trường.
3. **Quản lý vận hành**: Bảo trì, vận hành và quản lý tài sản.

## Status: 🚧 Planning
