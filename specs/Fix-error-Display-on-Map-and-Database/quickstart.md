# Quickstart: Validate Word Report Export Fix

1. Open a large project with many intersections and routes.
2. Open Word report export.
3. Preview an intersection and confirm the map image is not covered by overlays.
4. Preview a route and confirm only the selected route plus route intersections are visible.
5. Export with map images enabled.
6. Confirm the app does not show the WebView Out of Memory page.
7. Open the DOCX and confirm map images and site photo warnings are present.
